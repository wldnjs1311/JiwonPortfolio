    [모작] Valorant

    2025.03 - 2025.05 · 팀 (4인)

    장르와 만든 것을 한 줄로.

    • UDP 기반 데디케이티드 서버 구현. AWS에 연동하여 실제 네트워크 환경에서 동작하는 것을 확인.
    • A*와 Funnel알고리즘을 사용한 Navmesh 길찾기 구현
    • 상하체 분리 애니메이션 제어
    • 디퍼드 렌더링 파이프라인 + FPS 전용 렌더 패스
    • UDP 신뢰성 제공을 위한 자체 규칙 구현 : 시퀀스 번호를 이용한 동기화,ACK / 재전송
    • 서버 로직 구현 : 라운드 상태머신 + 매치 진행 로직 구현
    • 서버가 30FPS로 브로드캐스트하는 상태 스냅샷을 클라이언트 프레임레이트에 맞춰 보간하여 원격 플레이어의 움직임을 표현. 시퀀스 번호로 순서가 뒤바뀐 패킷을 폐기하고,NetworkConnector 컴포넌트를 부착하는 것만으로 임의 오브젝트를 동기화 대상으로 만들 수 있도록 설계.

    「Valorant」를 학습 목적으로 재구현한 모작이며, 프로그래밍은 직접 작성했습니다. 원본 리소스는 외부에 배포하지 않습니다.
